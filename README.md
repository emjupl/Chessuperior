# ♟️ Chessuperior – Extension for Chess.com

**Chessuperior** is a browser extension that automatically adds a convenient shortcut to external chess analysis to **Chess.com** (currently supports Chessigma.com). 

Analysis buttons are added directly to the game-over modal and alongside games on user profiles.

---

## ✨ Key Features

* **Quick Post-Game Analysis:** When you finish a game, a button with a direct link to external analysis automatically appears in the summary modal.

* **Match History & Profile Buttons:** The extension adds subtle analysis buttons next to game accuracy scores on profile tabs and game archives.
